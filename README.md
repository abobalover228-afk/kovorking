# Карта студенческих коворкингов

**Направление:** Инновационные технологии, бизнес и предпринимательство

---

## О проекте

Сервис, который отвечает на один вопрос: **где прямо сейчас можно сесть и работать**.

Проблема: студенту нужны стол, интернет, розетка и тишина. В общежитии этого нет, бесплатные залы закрываются к вечеру, а данные о доступных местах разбросаны.

Решение: единая карта доступных пространств Минска с фильтрами (бесплатно, открыто сейчас, розетки/Wi-Fi/тихо) и достоверными данными от самих студентов.

## Техническая информация

- **Карта:** Яндекс Maps API (до 25 000 запросов/сутки бесплатно)
- **Интерфейс:** React + TypeScript (для MVP)
- **Бэкенд:** PocketBase + SQLite (лёгкий бэкенд для прототипа)
- **Формат приложения:** PWA — устанавливается на телефон без App Store
- **Хостинг:** GitHub Pages (бесплатно), VPS ~10 $/мес для бэкенда
- **Стоимость запуска:** только время автора
